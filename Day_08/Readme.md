## Concepts Learned

### Aggregate Functions
Used to summarize data:
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

### GROUP BY
Groups data for analysis.

### HAVING
Filters grouped data.

### Window Functions
Performs advanced analytics without collapsing rows.
